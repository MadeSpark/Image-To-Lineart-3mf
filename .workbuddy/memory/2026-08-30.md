- 同时不再写入 `enable_support='1'`。
- UI 提示改为："已自动倒扣 180°，平整顶面贴热床、柱体向上收窄（SHRINKING），不需要支撑即可打印；打印完成后 A 面朝上直接使用。"

### 注意事项
- 180° X 轴旋转会沿 Y 轴镜像图案。如方向敏感，用户需在源图中垂直翻转后导入；后续可考虑在代码里自动预镜像补偿。

## 第 12 轮（审计推翻第 11 轮）：倒扣打印并没有解决可打印性，底板变成悬顶

### 触发
继续第 11 轮收尾验证时，重跑测试发现 `generator.test.ts` 里 ▼ 的 Z 区间断言失败
（`背景下层` 期望 [0, 0.6]，实际 [-0.6, 0]）——这是预览施加 180° 倒扣后的正确连带影响。
顺查下去，挖出一个被测试盲区掩盖的**结构性缺陷**。

### 关键发现：倒扣后「背景下层」是悬空天花板
- ▼ 几何：底面顶点 `z = zStart + maxH − avgH`（随灰度起伏），顶面固定 `zStart + maxH`（满铺平面）。
  即柱体**吊挂在平整顶棚下方**，柱尖朝下。
- 背景下层 `[0, zStart]` 是**实心满铺**底板，且在 `buildLightRelief3mfPackage` 里**无条件包含**
  （`if (faceBZMm > 0)`，与 reverseStack 无关）。
- 倒扣 180° 后：浮雕平整面落到 `−(zStart+maxH)` 贴热床（✓ SHRINKING），
  但背景下层被甩到模型**顶部** `[−zStart, 0]`，底面悬在柱尖之上。
- 只有 `avgH == maxH`（纯黑柱）才够得着底板底面，其余全是空腔。

### 实测数据（临时审计 tmp_flipPrintAudit.test.ts，64² 网格 / 浮雕高 1.4mm）
```
层 z=-0.56  占用=4225  悬空=3697  悬空率=87.5%   <- 背景下层第一层
底板底面 z=-0.600 处：有浮雕顶到的列 = 0/4225 = 0.00%
底板下方空腔高度：最大 1.350mm  平均 0.848mm
```

### 结构性硬约束（本轮最重要结论）
**免支撑 ⟹ 细节面（柱尖）必须朝上**。理由：尖端朝下贴 A 面 ⟹ 柱体吊挂在平整顶棚下 ⟹
柱高随灰度变化 ⟹ 柱尖下方必有空腔。而 A 面底板在柱尖另一侧，于是形成
「实心底板 + 空腔 + 实心浮雕」三明治——无论正打还是倒扣，总有一头悬空：
- 不倒扣：底板在热床 ✓，浮雕 GROWING、柱底悬空 ✗（需支撑）
- 倒扣：浮雕 SHRINKING ✓，底板成悬顶 87.5% 悬空 ✗（打不了）
- **填充空腔 = 各柱厚度变常量 = 图像消失**，所以"补平"不是出路。
→ **▼ + 保留 A 面底板 + 免支撑，三者不可兼得。**

### 测试盲区（必须记住的教训）
- `reverseStack3mfExport.test.ts` 传 `baseLoops: []` → 背景下层是**空网格（0 顶点）**，
  而 `expect(parsed['背景下层']).toBeTruthy()` 对空数组 `[]` 也是真值 → **断言一直是空的**。
- 该测试只取 `parsed['B面透光浮雕']` 一个网格做判据，**完全没有统计背景下层**。
  所以"倒扣后 floating=0 / SHRINKING"只对浮雕成立，对整个组合体不成立。
- 教训：**可打印性判据必须覆盖全部 mesh**；构造测试数据**底板轮廓必须给真实 loops**；
  `toBeTruthy()` 对空数组/空对象是假绿，应断言顶点数 > 0。
- 可复用审计法：临时 test 里 `buildLightRelief3mfPackage` → `unzipSync` → 解析 .model →
  按 (x,y) 分组成列 → 逐层求占用集合 → `unsupported = |S(z) \ S(z-层高)|`。
  底板需按"占满全部列"特殊处理（它只有外框顶点，内部无采样点）。
