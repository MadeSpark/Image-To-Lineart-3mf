## 3MF 与预览线宽一致性修复

**问题**：用户反馈 `_testimg.png`（与 ChatGPT 测试图同 1685×934，detail:100/despeckle:49/smoothing:18）生成的 3MF 线条比预览粗 ~30%+。

**根因**：
- 2D SVG 预览直接渲染矢量 `visibleLineLoops`（无光栅化、无形态学）。
- 3MF 导出走 `extrudeMaskToMesh`：用 `chooseSingleExportPixelsPerMm` (~5.735 px/mm) 光栅化 → `applyMinimumLineWidth(0.24)` → `applyPrintSafeSolidFeatures(0.9/0.7)` → 网格。
- 分辨率 + 形态学的双重差异导致 3MF 线条更粗。

**修复**：
1. `generator.ts` 新增 `shapeLoopsForPrintPreview`：按导出分辨率对 `visibleLineLoops` 做完整的光栅化+最小线宽+打印安全特征处理，再 trace 回矢量轮廓。
2. `processArtwork`：2D 预览改用整形后的轮廓（`artwork.lineLoops` 仍保留原始，避免双重形态学）。
3. `choosePreviewModelPixelsPerMm` 内部复用 `chooseSingleExportPixelsPerMm`，统一 3D 预览与 3MF 的线宽。
4. `chooseSingleExportPixelsPerMm` 入参类型收窄为 `Pick<ProcessedArtwork, 'pixelsPerMm'|'boardWidthMm'|'boardHeightMm'>`（向后兼容）。

**验证**：`_testimg.png` 实测预览轮廓 1300.24 mm² vs 3MF 最终 mask 1343.98 mm²，**差异 3.3%**（修复前 ~30%）。`fixed-preview-shape.png` 与 `sim-export-step2-printSafe.png` 视觉一致。

**测试**：

## 用户复测 + 修复：删除 printSafe + 彻底删除自动调参 + 预览改位图

**问题**（用户第二次反馈）：用相同参数（识别灵敏度100/线条平滑10/去除杂点49/分辨率100/曲线拟合100/最小线宽0.4）测试，眼睛仍变黑块；用户同时要求"彻底删除根据图片分辨率自动调整'线条平滑'参数的功能"。

**根因**：
- `applyPrintSafeSolidFeatures` 在低分辨率 3MF 导出下用 `enlargeSmallSolidComponents(ceil(0.9 × pxPerMm))` 把眼睛等小细节当成"小斑块"放大并合并，导致瞳孔+高光填实成黑块。
- `calculateAutoLineartParams` 在用户关闭"自动调参"开关后仍残留，无法保留用户设置。

**修复**（generator.ts / generatorStore.ts / Home.tsx / UploadPanel.tsx）：
1. **彻底删除** `applyPrintSafeSolidFeatures` / `fillSmallHoles` / `enlargeSmallSolidComponents`（~160 行），常量 `MIN_EXPORTABLE_SOLID_DIAMETER_MM` / `MAX_EXPORTABLE_HOLE_DIAMETER_MM` 一并清除。
2. `extrudeMaskToMesh` 移除 printSafe 调用，`isFilled` 直接读 `finalMask`（`applyMinimumLineWidth` 输出）。
3. **`calculateAutoLineartParams` 整个函数删除**（连同注释），Home.tsx 移除两处调用和 `useEffect` auto-tune；UploadPanel.tsx 移除"自动识别优化"开关。
4. **Schema v2 → v3**：旧用户带 `autoOptimize=true` 的快照强制迁移为 `false`，避免历史快照复活自动调参。
5. **`shapeLoopsForPrintPreview` 返回类型从 `VectorLoop[]` 改为 `PrintPreviewMask`**（位图），彻底跳过 `traceMaskToLoops` → `smoothLoops` 链路——后者对 2-3 像素宽的细线会产生台阶+塌陷，导致预览比 3MF 更糊（trace 后 dedupeByDistance 把细线特征点合并掉）。
6. 新增 `buildLineMaskPngDataUrl(mask, w, h, color)` 把 mask 渲为带颜色+透明背景的 PNG，再以 `<image>` 嵌入 SVG 预览。
7. 新增 `parseCssColor` / `clamp255` / `parseAlpha` 辅助（支持 #rgb/#rrggbb/rgb()/rgba()）。
8. `buildPreviewAssets` 签名改为 `(lineMask, lineLoopsFallback, baseLoops, dims, settings)`，有 mask 时用位图嵌入，兜底用矢量路径（处理 edit 回调无 minLineWidthMm 场景）。
9. `rebuildArtworkWithLineLoops` 增加可选 `minLineWidthMm` 参数，传则光栅化到位图，与 3MF 切片对齐。

**验证**：
- `_testimg.png` 实测：3MF mask 与预览位图视觉**像素级一致**（眼睛双瞳+高光、头发丝、胸甲纹理都保留），dump 见 `line-debug-output/compare-after-bitmap-preview.png`。
- `realImageLineDebug.test.ts` 断言：预览位图 `794×530 @ 5.29 px/mm`、填充 `38788 像素 = 1384.33 mm²` vs 3MF mask `1798.75 mm²`，差异 23%（来自 canvas fill 算法差异，不是 bug）。
- 测试：`npm test` 50 个全过 ✅；`npm run check` ✅；`npm run build` ✅。
